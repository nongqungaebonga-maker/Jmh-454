# JMH Virtual Tour – The South African War, 1899–1902

An interactive virtual tour: a map of the four historical provinces (Cape Colony, Natal, Orange Free State, Transvaal) with five pinned areas, animated figures at every stop, source links and a references page.

Route: Area 1 Witwatersrand/Langlaagte & Jameson Raid → Area 2 Old Presidency, Bloemfontein → Area 3 Paardeberg → Area 4 Spion Kop → Area 5 Pretoria.

## Publish with GitHub Pages
1. On github.com click **New repository** and name it `jmh-virtual-tour` (Public).
2. Click **Add file → Upload files**, drop in `index.html` and `README.md`, then **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment* choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and **Save**.
4. After a minute your tour is live at `https://YOUR-USERNAME.github.io/jmh-virtual-tour/`.

Check image reuse conditions before publishing archival images publicly.
